# Soko — Brand System

**Soko** (Lingala / Swahili: *market*) is Kinshasa’s verified classifieds marketplace — real people, real items, real prices — where the whole deal stays in the app.

Tagline (FR): **Le marché de confiance**  
Promise: *Annonces vraies. Personnes vraies. Prix vrais.*

---

## 1. Logo

### Assets

| File | Use |
|---|---|
| `assets/soko-logo-primary.png` | Primary lockup (symbol + wordmark) |
| `assets/soko-app-icon.png` | iOS / Android / PWA icon |
| `assets/soko-logo-variants.png` | Color / reverse / mono reference |
| `assets/soko-brand-banner.png` | Social, pitch, cover art |

### Symbol

A geometric marketplace canopy (three arches) that also reads as a subtle **S**. It means open trade, shelter, and gathering — not a shopping cart, not a flame.

### Clear space

Keep empty space around the logo equal to at least the height of the letter **o** in “Soko”. Do not crowd it with badges or text.

### Do

- Use full-color on white / light surfaces
- Use reverse (white mark) on `soko-forest`
- Use mono green when color is unavailable
- Keep the wordmark horizontal

### Don’t

- Recolor with Dubizzle red, purple, or neon
- Stretch, rotate, or add drop shadows / glow
- Place on busy photos without a solid scrim
- Replace the symbol with emoji or generic cart icons

## 2. Color

| Token | Hex | Role |
|---|---|---|
| Forest | `#0F3D2E` | Primary brand, headers, key UI |
| Amber | `#E8A317` | Accent, verified badges, CTAs (sparingly) |
| Sand | `#F5E6C8` | Warm surfaces, empty states |
| Clay | `#C45C26` | Alerts / “négociable” / secondary energy |
| Ink | `#14201B` | Body text |
| Mist | `#F3F1EC` | App background |
| Line | `#D9D4CB` | Dividers |
| Success | `#1F7A4C` | Verified / success states |
| Danger | `#B42318` | Scam report / destructive |

**Rule:** Amber is precious — use it for *verified*, *post*, and primary actions. Forest carries the rest.

---

## 3. Typography

| Role | Family | Notes |
|---|---|---|
| Display | **Fraunces** or **Libre Baskerville** | Brand moments, hero, empty states |
| UI / Body | **DM Sans** | App chrome, forms, lists |
| Numerals (prices) | **DM Sans** tabular | CDF / USD clarity |

Avoid Inter, Roboto, Arial, and system defaults for marketing surfaces.

### Type scale (mobile-first)

- Display: 32–40 / bold  
- Title: 22–24 / semibold  
- Body: 16 / regular  
- Meta: 13 / medium, muted ink

## 4. Voice & tone

**Personality:** Local, clear, serious about trust, warm without being childish.

| Do | Don’t |
|---|---|
| French-first, Kinshasa-real | Gulf / “premium Dubai” cosplay |
| Direct: “Annonce vérifiée” | Vague: “Get more visibility” |
| Practical meetup language | Fake corporate slang |
| Respect Lingala in key moments | Force English UI |

### Sample microcopy

- Empty chats: *Votre discussion est vide. Explorez le marché ou publiez une annonce.*
- Verified badge: *Vérifié Soko*
- Post CTA: *Vendre sur Soko*
- Trust line: *Numéro masqué. Discussion dans l’app.*

---

## 5. Product UI principles

1. **One composition** on first viewport — brand, search, categories; no dashboard clutter.
2. **Trust visible** — verified badges beat soft banners.
3. **No cards in hero** — cards only when they wrap an action.
4. **Light, warm surfaces** — Mist / Sand, not flat sterile white forever.
5. **Center action** — Publier (+) is the gravity well of navigation.
6. **Performance-first** — flat icons in-app; rich brand art only on marketing.

---

## 6. Iconography

- In-app: 1.5px stroke, rounded joins, forest ink
- Categories: simplified illustration (not heavy 3D renders) for low-end Android
- Verified: amber check in forest seal

---

## 7. Kinshasa launch categories (seed)

Prioritize liquidity visual weight on:

1. Téléphones & électronique  
2. Véhicules & motos  
3. Immobilier (location + vente)

Other categories exist in taxonomy but stay quieter until supply is real.
